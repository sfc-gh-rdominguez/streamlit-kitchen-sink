# Streamlit in Snowflake — Kitchen Sink

A teaching repo for three Streamlit-in-Snowflake patterns:

1. Owner's rights vs. restricted caller's rights
2. CI/CD with GitHub Actions (dev → prod)
3. Role hierarchy for sharing & governance

Snowflake objects are created by idempotent SQL under `sql/`. See `docs/` for details.
